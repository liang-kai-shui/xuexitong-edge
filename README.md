# 学习通视频播放助手

面向 Microsoft Edge 的 Manifest V3 本地扩展，提供学习通课程页的视频控制、章节导航和可选的 DeepSeek 练习辅助。

当前版本：**1.7.8** · 无第三方运行依赖 · [更新记录](CHANGELOG.md) · [验证记录](TEST-REPORT.md)

1.7.8 支持将题干及选项中已加载、可读取的图片拼入题图，先视觉转录再作答；不含混淆字体的图片题也会走视觉流程。破图、加载超时或跨域不可读会明确提示题号，不根据文件名猜测缺失公式。

1.7.7 区分后台暂停与播放故障：页面隐藏且视频已暂停时等待恢复可见，不反复调用播放、不消耗重试次数；恢复窗口后按续播开关继续。已在后台正常播放的视频保持原状，不保证平台允许最小化播放。

1.7.6 支持普通窗口与 InPrivate 各运行一个课程标签页，分别保留运行状态、页面报告与答题任务；同一环境内仍只允许一个运行页。包含下述 1.7.5 题型修复。

1.7.5 修复「其它」文字作答题被题干中的“排序、编程、填空”等词误判的问题：没有选项且存在可读取文字编辑器时，优先按简答题处理。未识别题目的诊断新增具体题号、固定原因类别和选项数量。

1.7.4 默认开启「失败题随机选择（不含简答题）」：客观题的模型答案为空、格式无效或请求失败时，从已识别选项中随机选择并明确标注，保留其他有效答案。关闭开关可恢复严格校验流程。字形读取和分批答题每页最多并发 2 个请求，保留所选模型与思考强度。

1.7.3 增加原生任务点状态衔接：当前内容显示“任务点已完成／任务点已经完成”，或存在原生完成标记时，确认状态稳定约 2 秒后优先进入本节紧接的“2 练习”。重新打开已完成的视频，也无需再次收到播放结束事件。橙色“任务点”、其他未完成任务、验证提示或未加载完整的资源仍保持等待；右侧章节绿勾、播放器进度比例和正文中的完成字样不作为本项证据。练习页签点击无响应时停止，不回退到下一章节。受“自动进入后续步骤”开关控制。

1.7.2 修复字形读题的返回格式处理：兼容完整 JSON 代码块，空内容或不可解析 JSON 最多重新读图一次；不会修补或猜测程序表达式。严格模式下，读不清、题号或选项不匹配时仍停止。失败诊断只包含类别、字符数、是否代码块和尝试次数，不保存模型原始返回。格式重试可能增加一次视觉接口费用。

## 功能

- 识别学习通课程学习页及播放器 iframe，支持多门课程。
- 跟随原播放器倍速，或选择 1～2 倍速；支持暂停、停止及有限次数的意外暂停恢复。
- 视频结束后进入紧接的学习步骤；识别图文讲义、章节练习和已提交结果页。
- 可选接入 DeepSeek，生成选择题与简答题建议，支持填写、同步富文本编辑器及章节练习提交流程。
- 对混淆字体文字题按实际字形生成图像进行视觉转录；读题失败时，已识别选项的客观题按随机兜底开关处理，简答题停止处理。
- **拖住浮窗标题栏即可移动；右上角「−」收起、「＋」展开。记住位置和收起状态，收起不暂停运行。**
- 提供诊断日志；遇到学习确认、验证码或无法识别的任务时停止并提示处理。

扩展不能保证模型答案正确、平台记录学时或所有课程结构均兼容。请遵守所在学校和课程的学习要求，并核对生成内容。验证码、人脸验证与播放器「继续学习」确认需要本人处理。

## 安装

1. 点击仓库 **Code → Download ZIP** 并解压，或使用 Git 克隆。
2. 在 Edge 打开 `edge://extensions`，开启「开发人员模式」。
3. 点击「加载解压缩的扩展」，选择 **`edge-extension`** 文件夹，而不是仓库根目录。
4. 从学习通课程列表进入课程学习页，刷新页面，确认浮窗显示 **v1.7.8**。
5. 首次先在原播放器中点击播放，再点击助手「开始 / 继续」。自动播放策略可能要求这次真实点击。

视频控制无需 Node.js 或 API Key。开发验证才需要 Node.js；DeepSeek 功能需要单独配置密钥与余额。

更新时覆盖扩展文件，在 `edge://extensions` 对扩展点击「重新加载」，然后刷新课程页。当前扩展中已保存的设置会保留。

## 使用

### 播放与浮窗

默认跟随播放器倍速；选择固定倍速后会应用到后续识别到的视频。暂停和停止期间不持续接管倍速。

最小化或切换标签页后，如果浏览器报告页面隐藏且视频已暂停，助手进入“后台暂停，等待窗口恢复可见”，保留运行状态。恢复可见后，开启「意外暂停后续播」时自动尝试继续；关闭此项或手动暂停则不自动恢复。后台仍正常播放的视频不会被本功能暂停；验证码、学习确认及可见页面每分钟最多 6 次重试保护继续生效。诊断新增页面 visibility、视频 waitingForVisible 和 resumeAttempts。

标题栏是拖动区域，内部按钮和下拉框保持正常操作。最小化只保留标题与展开按钮；位置和收起状态保存在扩展本地，窗口尺寸变化时会限制位置，避免浮窗移出屏幕。

同一课程内章节切换可保留运行；切换课程或班级会清除旧任务状态、取消旧模型请求，等待再次点击开始。新标签页默认不运行；普通窗口与 InPrivate 环境各可接管一个课程标签页，同一环境中的其他运行页需先暂停或停止。

### 普通窗口与 InPrivate

1. 更新扩展后，在 Edge 扩展详情中确认已开启「允许在 InPrivate 中」。然后刷新普通和 InPrivate 的课程页，分别点击开始。
2. 普通窗口与 InPrivate 各允许一个运行页；多个普通标签页之间、多个 InPrivate 标签页之间仍互斥。恢复后台服务时也按这两个环境分别检查。
3. 课程状态、模型请求、填写结果和暂停操作按标签页隔离。账号登录由浏览器和学习通管理，扩展不读取或复制登录 Cookie，不保证平台允许多端同时学习。
4. 同一 Edge 配置中的 DeepSeek 密钥、模型设置和浮窗布局仍为扩展共用设置；两边调用 API 都计入同一已配置密钥。

扩展继续使用 Chromium 的 [spanning 模式](https://developer.chrome.com/docs/extensions/reference/manifest/incognito)，仅依据浏览器发送者的 incognito 标识分组，不接受网页消息自行声明所属环境。

### DeepSeek 配置

1. 点击扩展工具栏图标，或在「DeepSeek 章节答题」中点击「密钥与模型设置」。
2. 输入自己的 API Key，选择模型和思考选项并保存，也可导入设置页支持的本机 JSON。
3. 手动模式下点击「生成答案与解析」，核对后再填写。自动模式可执行章节练习生成、填写、校验、提交及确认流程。
4. 「失败题随机选择」默认开启：单选／判断随机选一个现有选项，多选随机选一个非空选项组合；标注「随机兜底（非模型答案）」，可能答错，并可随自动流程提交。模型有效答案不变。关闭后遇到无效答案按严格校验流程停止，格式问题最多逐题重试两次。
5. 简答题没有选项，仍需有效文字答案；不支持的题型、不可识别的选项、暂停、切页和验证提示仍会停止。随机兜底不会处理验证码或学习确认。
6. 点击「暂停」或「停止」可中止流程；不会无限重试接口。字形读题失败仍最多重读一次，再按题型及开关处理。

支持已识别的文字单选、多选、判断和简答题。题干或选项内的图片需要已加载且允许 Canvas 读取；破图先刷新课程页，仍无法显示时需恢复原题图片。跨域不可读图片、直接嵌入的 SVG／MathML／canvas 公式、填空、上传题、不可访问的编辑器及视频互动题可能需要人工处理；视觉转录也可能出错。

模型、思考和视觉接口均可能产生 API 费用。模型选项随服务变化，以 [DeepSeek 官方文档](https://api-docs.deepseek.com/)为准。

## 隐私与权限

| 权限 | 用途 |
| --- | --- |
| `storage` | 保存扩展设置、浮窗布局与任务会话 |
| `scripting` | 调用页面已有编辑器，执行固定的本地适配函数 |
| `https://*.chaoxing.com/*` | 识别课程学习入口及其跨帧内容 |
| `https://api.deepseek.com/*` | 用户启用答题功能时请求模型接口 |

密钥保存在当前浏览器配置的扩展 `chrome.storage.local` 中，未加密、不跨设备同步；仅扩展可信上下文可读，内容脚本不获取密钥。输入框不回显已有密钥，留空保存会保留原值。

答题时向 DeepSeek 发送题干、题型和选项；混淆字体或图片题目还会发送仅包含该题题干和选项的拼接图像。不发送登录 Cookie、课程链接或整页截图。诊断不含密钥、Cookie 和地址查询参数，但会包含页面路径、课程编号与运行状态，分享前请检查。

`.local/`、密钥配置、环境变量文件及临时文件不纳入 Git，也不包含在发布包中。请勿把真实密钥写入源码或 Issue。密钥若已公开，应在提供方控制台撤销并重新生成。

## 支持范围与排查

支持学习通 HTTPS 域名的 `/mycourse/studentstudy`、`/mycourse/stu` 及 mooc-ans、mooc2-ans 同类课程学习入口，动态识别有效课程与班级参数。登录页、课程列表和考试入口不启用。新播放器、学校专属域名和不同题目结构仍可能需要适配。

| 问题 | 处理方式 |
| --- | --- |
| 没有浮窗或仍显示旧版本 | 确认扩展目录和站点访问权限，重载扩展后刷新课程页 |
| 浏览器阻止自动播放 | 在视频所在 iframe 内手动点击播放，再启动助手 |
| 出现「继续学习」或验证提示 | 本人完成提示，再点击助手开始 |
| 没有进入下一节 | 检查练习提交和未完成任务，必要时使用「下一步 / 下一节」 |
| DeepSeek 返回 401 / 402 / 429 | 分别检查密钥、余额、限流，不要反复提交 |
| 异常暂停或控件行为变化 | 关闭其他同类脚本，并尝试关闭实验兼容选项 |

鼠标离开拦截和前台读取兼容属于实验选项，可能影响控件行为，不能保证解决后台挂起或平台检测，也不能保证学时计入。异常时关闭对应选项，并按课程要求正常学习。

## 开发与验证

建议 Node.js 22 或更高版本，无需安装 npm 依赖。

```sh
npm run check
npm test
```

Windows 已安装 Edge 时，可运行本地模拟页回归：

```sh
npm run test:browser
```

浏览器回归使用独立临时配置、本地页面、模拟媒体及模拟 DeepSeek 响应，不访问真实课程，不消耗 API 费用。可用 `node tests/browser-smoke.cjs --fallback-only` 专测随机兜底与关闭开关。详细验证范围见 [TEST-REPORT.md](TEST-REPORT.md)。

`tests/deepseek-live.cjs` 是需要主动运行的真实 API 检查，读取本机 `.local/deepseek-config.json`，会产生费用；CI 不运行它。

```text
edge-extension/          扩展源码与设置页
tests/                  单元测试、本地浏览器回归与显式 API 联测
scripts/check.cjs       语法和清单检查
.github/workflows/      自动检查
CHANGELOG.md            版本变更
TEST-REPORT.md          验证证据与边界
OPEN-SOURCE-REVIEW.md    开源方案调研
```

贡献前请阅读 [CONTRIBUTING.md](CONTRIBUTING.md)。
