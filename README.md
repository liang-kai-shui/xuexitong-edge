# 通用网课助手（xuexitong-edge）

面向 Microsoft Edge 的 Manifest V3 本地扩展。项目从「学习通课程页播放助手」演进为**多平台通用网课引擎**：核心播放/导航/答题能力与站点解耦，学习通保留完整适配器，其他平台通过适配器或通用语义识别接入。

当前版本：**2.0.1** · 无第三方运行依赖 · [更新记录](CHANGELOG.md) · [验证记录](TEST-REPORT.md)

## 功能

- **播放控制**：自动播放、意外暂停续播、静音、固定倍速（1～3 倍）或跟随播放器；iframe 内嵌播放器同样生效。
- **自动下一节**：视频正常播完后进入后续步骤 / 下一节；学习通支持顶部步骤页签与右侧章节目录，其他平台使用语义识别（「下一节 / 下一课 / 下一页 / 继续」）。
- **多平台**：内置超星学习通 / 泛雅 / 学银在线、智慧树、中国大学 MOOC、学堂在线、雨课堂、智慧职教、优学院适配器。
- **任意网站**：可对任意视频课程网站授权启用「通用模式」，动态注册内容脚本，重启浏览器自动恢复。
- **AI 答题**：DeepSeek 官方接口或任意 OpenAI 兼容接口；生成 → 填入 → 逐题校验 → 提交（学习通默认全自动，其他平台默认只填入、手动提交）。
- **新版作业页兼容**：学习通 `/mooc-ans/api/selectWorkQuestion` 作业页的隐藏提交字段、受控组件重渲染、UEditor 简答编辑器均有专门处理；填写失败时停止提交并输出结构诊断。
- **安全边界**：验证码、滑块、人脸、平台风险提示、播放器「继续学习」确认均停止自动化并提示本人处理，不做绕过。

扩展不能保证模型答案正确、平台记录学时或所有课程结构均兼容。请遵守所在学校和课程的学习要求，并核对生成内容。

## 安装

1. 点击仓库 **Code → Download ZIP** 并解压，或使用 Git 克隆。
2. 在 Edge 打开 `edge://extensions`，开启「开发人员模式」。
3. 点击「加载解压缩的扩展」，选择 **`edge-extension`** 文件夹，而不是仓库根目录。
4. 打开课程学习页并刷新，确认面板显示 **v2.0.1**。
5. 第一次先在原播放器中点击播放，再点面板「开始 / 继续」（浏览器自动播放策略可能要求这次真实点击）。

视频控制无需 Node.js 或 API Key。开发验证需要 Node.js 22+；AI 答题需要单独配置密钥与余额。

更新时覆盖扩展文件，在 `edge://extensions` 对扩展点击「重新加载」，然后刷新课程页；已保存的设置会保留。

## 使用

### 面板

面板固定在右下角，可拖动标题栏移动、点右上角按钮收起；位置和收起状态会被记住。

| 控件 | 说明 |
| --- | --- |
| 开始 / 继续 | 启动自动播放与自动化。浏览器拦截自动播放时，先手动点一下视频再点这里 |
| 暂停 / 停止 | 暂停只停播放控制；停止会结束本次会话 |
| 下一步 / 下一节 | 手动触发一次页面切换（自动识别失败时使用） |
| 播放倍速 | 跟随播放器 / 1 / 1.25 / 1.5 / 1.75 / 2 / 2.5 / 3 倍 |
| 意外暂停后续播 | 平台播放器因鼠标移出、失焦而暂停时自动续播 |
| 后台播放兼容（实验） | 修正页面对 `document.hidden / visibilityState / hasFocus` 的读取；不置顶窗口 |
| 自动进入后续步骤 | 视频正常播完后自动点击下一节 |
| 自动作答 | 学习通：生成 + 填写 + 校验 + 提交；其他平台：生成 + 填写 |
| 自动提交（实验） | 仅辅助模式平台显示；开启后尝试自动提交 |
| 静音 | 自动静音播放 |

同一时间只接管一个课程标签页；同课程切换章节保留运行，切换课程或班级会取消旧任务。

### AI 答题

- 学习通默认「生成 → 填入 → 逐题校验 → 提交 → 等待平台确认」，校验失败停止并提示，不会盲目提交。
- 其他平台默认辅助模式：答案填入并校验，由你核对后手动提交；可在设置页开启该站点的「自动提交（实验）」。
- 混淆字体（学习通常见）题目按页面字形渲染为小图，交给模型视觉转录；无法完整转录时停止。
- 每页最多 40 题，按 5 题一批；返回题号/结构不匹配会自动逐题重试，仍失败则停止。
- 验证码、滑块、人脸、弹题、平台风险提示：自动暂停并提示手动处理。
- 设置页支持 DeepSeek 官方接口与任意 OpenAI 兼容接口（自定义 Base URL / 模型），密钥只保存在扩展本地存储，内容脚本与网页无法读取。

### 为任意网站启用通用模式

- 方式一：打开目标网站 → 点扩展图标 →「为此网站启用通用模式」→ 在浏览器弹窗中允许该域名。
- 方式二：设置页 →「自定义网站」→ 输入域名（如 `course.example.com`）→ 添加并授权。

启用后打开该网站的视频课程页，右下角会出现助手面板。通用模式的按钮与题目识别均基于页面语义，不依赖站点私有 DOM。

## 开发

使用 Node.js 22 或更高版本，无需安装 npm 依赖：

```sh
npm run check        # 语法 + manifest 一致性
npm test             # 单元测试（站点识别 / 策略 / 文本 / AI 校验）
npm run test:dom     # DOM 语义测试（自动查找本机 Edge/Chrome）
npm run test:e2e     # 端到端测试（无头浏览器加载真实扩展 + 本地假课程页）
npm run test:browser # 上两项浏览器测试
```

无头测试需要本机安装 Edge 或 Chrome；可用 `BROWSER_PATH` 环境变量指定浏览器路径。CI 只跑 `check` 与单元测试，浏览器测试在本地运行（见 [CONTRIBUTING.md](CONTRIBUTING.md)）。

### 新增站点适配

适配器是纯声明 + 可选覆盖，新增平台只需在 `core/adapters/` 添加文件，并在 `manifest.json` 与 `core/files.js` 中按顺序登记：

```js
XXTSites.register({
  id: "example",
  name: "示例平台",
  hosts: ["example.com"],          // 自动匹配子域名
  urlHints: [/\/learn\//i],       // 课程页 URL；null = 整站弱匹配（出现媒体/题目才激活）
  capabilities: { quiz: "assist", autoSubmit: false, lesson: false, practiceStep: false, catalog: false, blockerDialogs: false },
  hints: {                        // 可选：选择器提示，缺省时使用通用语义识别
    quizRoots: [".question-item"],
    nextSelectors: [".next-btn"],
    nextText: /^(下一节|下一课)$/,
    stepSelectors: [".step-tabs > li"],
    catalogSelectors: [".chapter-tree .item"]
  },
  // 可选：完全覆盖通用实现
  nav: { steps, next, videoStep, practiceStep, signature, catalog, isCatalogTarget },
  lesson: { scan },
  quiz: { id, collect, extras, submitButtons, hiddenAnswer, diagnose },
  messages: { nextHint: "未找到下一步按钮，请手动点击" }
});
```

适配器不得在加载时访问 DOM；所有 DOM 操作通过函数参数或运行时 `document` 完成，保证 Service Worker 也能安全 `importScripts`。

## 权限说明

| 权限 | 用途 |
| --- | --- |
| `storage` | 保存 AI 设置、站点偏好、默认行为、面板位置 |
| `scripting` | 为自定义站点动态注入内容脚本；在 MAIN world 写入富文本编辑器 |
| `activeTab` | 从弹窗读取当前标签页、为当前站点即时注入 |
| 内置平台站点权限 | 仅在对应课程网站运行内容脚本 |
| `optional_host_permissions` | 仅为用户主动添加的自定义网站 / 自定义 AI 接口申请 |

扩展不收集、不上传任何浏览数据；AI 请求只包含当前页面的题干与选项（以及混淆字体题目的题干小图）。

## 已知限制

- 视频必须由页面自身的 `<video>/<audio>` 元素承载；私有播放器无法控制，但通用模式仍会显示面板。
- iframe 中的播放器需要该 iframe 域名也在授权范围内（内置平台已包含其子域，自定义网站会同时申请主域与子域）。
- 跨域 iframe（如视频 CDN 独立域名）不会被注入脚本，只能通过顶层页面元素间接控制。
- 自动答题的题目识别为启发式：平台改版后可能需要更新适配器；识别不确定时默认停止而不是乱填。
- 后台标签页中浏览器会节流定时器；「后台播放兼容」只修正页面可见性读取，不能绕过所有平台的风控策略。
