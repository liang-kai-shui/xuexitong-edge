DeepSeek 答题设置

打开一键学习启动面板：登录后进入课程和未完成章节。

点击课程面板的“生成答案与解析”时，将该页识别到的题干和选项发送至 DeepSeek 官方 API。接口会产生 API 用量费用。

开启思考会增加等待时间和 API 用量。遇到混淆字体或题目图片时，先用 DeepSeek Flash 视觉接口读取题图，再用所选模型作答；会额外发送仅包含题干和选项的图像，不发送整页截图。简答题识别失败时停止填写，客观题按随机兜底开关处理；图片加载失败或跨域不可读时先提示处理。

读取设置…

密钥仅保存在当前 Edge 配置的扩展本地存储中，未加密；内容脚本不会获得密钥。全自动模式会生成、填写并提交答案；可在课程面板取消勾选该模式，改为手动核对提交。
